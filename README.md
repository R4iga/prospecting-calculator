# Prospecting Calculator

A modern calculator for the Roblox game **Prospecting**.

## Features

- 🎯 Drop Chance Calculator
- 📊 Build Planner (15+ builds)
- 🗺️ Optimal Dig Strategy
- 📍 Multi-Material Locations
- 🔧 Equipment Explorer (300+ items)
- 📋 Copy Strategy to Clipboard
- 🎨 Animated UI
- 🌐 Works Offline (pure HTML/CSS/JS)

## How to Use

1. Open `index.html`
2. Select mineral + location
3. Adjust luck, capacity, method
4. View chances, goals, time estimates
5. Pick a build for equipment + dig strategy

## Builds

**Stage I:** Luck Efficiency I., Size Boost I.
**Stage II:** Luck Efficiency II., Size Boost II.
**Stage III:** Luck Efficiency III.A/B, Hybrid III., Size Boost III., Items Farming III., Treasure/Geode III.
**Stage IV:** Luck Efficiency IV.A/B, Hybrid IV.B., Size Boost IV., Items Farming IV., Money Printer.
